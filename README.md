# PawMatch 🐾

PawMatch is a mobile-first animal adoption app for Lithuania, built with Expo and React Native.

## Current prototype
- Browse dog and cat profiles
- Filter by animal type
- Like or pass on profiles
- Save favourites during the current session
- View shelter contact details
- Lithuanian-first interface

**Important:** the current profiles are clearly marked as demo examples. They are not live shelter listings and do not represent confirmed partnerships.

## Run locally
1. Install Node.js (20.19.4 or newer).
2. In this folder run `npm install`.
3. Run `npx expo start`.
4. Press `w` for web, or scan the QR code with Expo Go on your phone.
